## 🏗️ Flagship Projects

### 🔹 [ForgeVision](https://github.com/KhemajiThakor/ForgeVision) – Industrial Computer Vision System
> **Production-grade defect detection system for automated quality inspection**

**Backend Architecture:**
- ⚡ **Real-time inference API** serving YOLO models via FastAPI
- 🎥 **Video stream processing** with frame-level analysis pipeline
- 🚀 **GPU-accelerated serving** with model optimization (TensorRT/ONNX)
- 🐳 **Containerized deployment** with Docker multi-stage builds
- 📊 **Inference monitoring** with Prometheus metrics

**Technical Highlights:**
- Sub-100ms inference latency on 1080p frames
- Horizontal scaling with Kubernetes HPA
- Async request handling for concurrent streams
- Redis-based result caching layer

**Stack:** `PyTorch` `FastAPI` `OpenCV` `Docker` `Redis` `YOLO`

---

### 🔹 [Feature Store](https://github.com/KhemajiThakor/FeatureStore) – ML Data Infrastructure
> **Centralized feature management for consistent training and inference**

**System Design:**
- 🗄️ **Dual-mode serving**: Offline (batch) + Online (real-time) feature retrieval
- 🔄 **Feature versioning** with backward compatibility
- ⚡ **Low-latency serving** (<10ms p99) via Redis + PostgreSQL
- 🔧 **Feature transformation pipeline** with Pandas/Polars
- 📈 **Feature monitoring** for drift detection

**Backend Capabilities:**
- RESTful API for feature registration and retrieval
- Time-travel queries for point-in-time correctness
- Feature lineage tracking for reproducibility
- Batch materialization jobs with Airflow

**Stack:** `FastAPI` `PostgreSQL` `Redis` `Pandas` `Docker`

---

### 🔹 [GuardSQL Agent](https://github.com/KhemajiThakor/GuardSQL) – Intelligent Query Validation System
> **AI-powered SQL security and validation layer**

**Core Features:**
- 🛡️ **Query validation engine** with rule-based + LLM-assisted analysis
- 🚨 **Risk scoring system** for unsafe operations (DROP, DELETE, etc.)
- 🔍 **Schema-aware validation** with metadata integration
- 📝 **Query rewriting** for optimization suggestions
- 🔐 **Access control enforcement** at query level

**Backend Architecture:**
- FastAPI service with async query processing
- LLM integration for semantic analysis
- PostgreSQL for audit logging
- Redis for query pattern caching

**Stack:** `FastAPI` `LLM APIs` `PostgreSQL` `Redis` `SQLAlchemy`

---

### 🔹 [ModelHub](https://github.com/KhemajiThakor/ModelHub) – Model Registry & Deployment Framework
> **Centralized ML model lifecycle management system**

**Platform Features:**
- 📦 **Model versioning** with artifact storage (S3/MinIO)
- 🚀 **One-click deployment** to staging/production environments
- 📊 **Model performance tracking** with A/B testing support
- 🔄 **Rollback capabilities** for failed deployments
- 📈 **Inference metrics** collection and visualization

**Technical Implementation:**
- RESTful API for model registration and serving
- Docker-based model containerization
- Kubernetes operator for deployment orchestration
- MLflow integration for experiment tracking

**Stack:** `FastAPI` `MLflow` `Docker` `Kubernetes` `PostgreSQL` `S3`
